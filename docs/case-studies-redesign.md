# Case studies, editorial edition

All nine case studies were rebuilt on `redesign-preview` in a seven-part format inspired by
portfolio.designwithdaria.com: hero, context, my role, three or four design decisions, an interactive piece,
outcome and reflection. The homepage is unchanged. Nothing has been deployed.

Copy lives in `src/content/stories/<project>.ts` (one file per project), and layout lives in `src/components/story/`.
`/work/[slug]` uses the new page whenever a story exists for that slug. All nine slugs have one, so the old
layout in that file is now unused (it's kept as a fallback).

## New assets and how they were made

- `public/work/natasha/v2/`: immersive and panel screens, voice-bar states, prompt chips, Natasha button states, and
  orb animations (Listening, Thinking, Thinking → speaking, Pause). Generated by `tools/mockups/natasha-block-assets.cjs`.
  The `*-l.webp` versions are extended at the top to the laptop's 0.593 screen ratio, so nothing is cropped.
- `public/work/builder-design-system/v2/buttons/`: 8 styles × 4 sizes × 4 states, cut from the component set export.
- `public/work/internshala/cs/in-ui-hd.webp` and `in-ui-zoom.webp`: the interface audit, rebuilt from its original
  1816 × 952 Figma fill (previously only an 813 px copy existed). Generated by `tools/mockups/internshala-audit.cjs`.
- `public/work/basecamp/cs/bc-s*.webp`: the final page cut at its section breaks (`tools/mockups/basecamp-sections.cjs`).
